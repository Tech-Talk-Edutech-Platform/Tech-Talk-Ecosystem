# Tech-Talk-Tutors-Dashbord

Progressive Web App (PWA): If you already have a web dashboard, you can turn it into a PWA with a few lines of code. This allows parents to "install" your website onto their phone home screen and receive native mobile push notifications without an app store.

Instaling Sanity CMS Studio
npm create sanity@latest -- --template clean --create-project "TechTalkHub-Admin" --dataset production

installing sanity to my website
npm install next-sanity
